# Bitwise Operators

Solved on **GFG** · Difficulty: **Basic** · Category: **Bit Manipulation**

[View problem](https://www.geeksforgeeks.org/batch/dsa-cpp-rkgit/track/bitmagic-dsa-cpp-rkgit/problem/bitwise-operators)

## Solution

```cpp
a = int(input())
b = int(input())
c = int(input())

# code here
d=a^a
e=c^b
f=a&b
g=~e
print(d, e, f, g)
```
